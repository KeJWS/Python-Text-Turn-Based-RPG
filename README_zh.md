## Introduction
该项目旨在提供可扩展且实用的回合制 RPG 系统。我尝试重现经典的 RPG/JRPG 体验，包括自定义法术、连击、物品、装备、敌人……

您可以在任何项目中自由使用此代码。随着时间的推移，我会尝试更新它，提出新的想法并改进现有的想法。

## Setup and launch
即使该项目是使用Python 3.9进行的，您也应该能够使用任何版本的Python 3进行运行。如果您不知道如何安装Python 3，我建议您关注[本教程](https://phoenixnap.com/kb/how-to-install-python-3-windows)。

下一步是用git克隆这个存储库。如果您不知道如何安装git，则可以关注[本教程](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)。您可以使用以下git命令来克隆此存储库：
```git
git clone https://github.com/rodmarkun/Python-Text-Turn-Based-RPG
```

拥有存储库后，您可以使用以下命令运行“游戏”：
```shell
python game.py
```

## Features
- 高级战斗系统
- 玩家状态和能力系统
- 玩家库存和金钱系统
- 使用和丢弃物品
- 商店（购买和出售物品）
- 装备定制
- 敌人定制
- 技能定制（法术和连击）
- 事件（随机战斗、商店、冒险……）
- 任务系统
- 连击基于实际装备
- 具有不同目标的法术和连击（选定目标、施法者、所有敌人、所有盟友等）
- 召唤和多盟友战斗
