
### **颜色代码**（适用于大多数终端）
| 颜色 | 代码 | 说明 |
|------|------|------|
| 黑色 | `\033[30m` | 设置前景色为黑色 |
| **红色** | `\033[31m` | **设置前景色为红色** |
| **绿色** | `\033[32m` | **设置前景色为绿色** |
| **黄色** | `\033[33m` | **设置前景色为黄色** |
| **蓝色** | `\033[34m` | **设置前景色为蓝色** |
| **洋红** | `\033[35m` | **设置前景色为洋红色（紫色）** |
| **青色** | `\033[36m` | **设置前景色为青色（蓝绿色）** |
| **白色** | `\033[37m` | **设置前景色为白色** |
| **默认前景色** | `\033[39m` | **重置为默认前景色** |

### **背景颜色**
| 颜色 | 代码 | 说明 |
|------|------|------|
| 黑色背景 | `\033[40m` | 设置背景色为黑色 |
| **红色背景** | `\033[41m` | **设置背景色为红色** |
| **绿色背景** | `\033[42m` | **设置背景色为绿色** |
| **黄色背景** | `\033[43m` | **设置背景色为黄色** |
| **蓝色背景** | `\033[44m` | **设置背景色为蓝色** |
| **洋红背景** | `\033[45m` | **设置背景色为洋红色（紫色）** |
| **青色背景** | `\033[46m` | **设置背景色为青色（蓝绿色）** |
| **白色背景** | `\033[47m` | **设置背景色为白色** |
| **默认背景色** | `\033[49m` | **重置为默认背景色** |

### **文本格式**
| 格式 | 代码 | 说明 |
|------|------|------|
| **重置所有格式** | `\033[0m` | **重置所有文本样式** |
| **加粗** | `\033[1m` | **设置文本加粗** |
| **淡色（较暗）** | `\033[2m` | **设置文本颜色较暗** |
| **斜体** | `\033[3m` | **设置斜体文本（部分终端不支持）** |
| **下划线** | `\033[4m` | **添加文本下划线** |
| **闪烁** | `\033[5m` | **文本闪烁（部分终端不支持）** |
| **反转颜色** | `\033[7m` | **交换前景色和背景色** |
| **隐藏文本** | `\033[8m` | **隐藏文本（适用于密码输入）** |

### **示例代码**
```python
print("\033[31m这是红色文本\033[0m")
print("\033[32m这是绿色文本\033[0m")
print("\033[1;34m这是加粗蓝色文本\033[0m")
print("\033[7;35m这是反转洋红文本\033[0m")
```
